# 🚫 MAX Blocker

**Описание:**  
MAX Blocker — скрипт для блокировки всех запросов к серверам приложения **MAX** (`max.ru`), делая его полностью нерабочим на всех устройствах, подключённых к вашей сети. Можно использовать на ПК и мобильных устройствах через хотспот.  

**Примечание:** В будущем планируется добавить YouTube и Discord, чтобы они работали корректно через ваш хотспот.
