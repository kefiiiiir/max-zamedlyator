# 🚫 MAX Zamedlyator

**Описание:**  
MAX Zamedlyator — скрипт для блокировки всех запросов к серверам приложения **MAX** (`max.ru`), делая его полностью нерабочим на всех устройствах, подключённых к вашей сети. Можно использовать на ПК и мобильных устройствах через хотспот.  

**Примечание:** В будущем планируется добавить обход блокировки YouTube и Discord, чтобы они работали корректно через ваш хотспот.

## ⚡ Требования (Для скрипта Python)

- Windows (для работы с firewall)
- Python 3.x
- Модули: `dnslib`, `dnspython`

---

## 🛠 Как использовать 
- Подключите компьютер к интернету.
- Запустите скрипт или .exe (желательно с правами администратора, но можно и без). Скрипт создаст локальный DNS-сервер и добавит firewall правила для блокировки MAX.
- Создайте Wi-Fi хотспот на ПК с SSID (например, Sch00lWiFi).
- Подключите устройства (телефоны, планшеты, ноутбуки) к вашему хотспоту. Скрипт начнёт блокировать MAX автоматически.

## ✅ Что делает скрипт
 - Блокирует домен max.ru и все связанные с ним IP.
 - Приложение MAX не может соединяться с серверами → перестаёт работать.
 - Выводит в консоль, какие домены заблокированы.

---

## ❓ Вопросы и ответы (Q&A) 
 - Q1: Как добавить больше заблокированных доменов или IP?
   A: В скрипте найдите списки: BLOCKED_DOMAINS = ["web.max.ru", "max.ru", ...] и добавьте новый URL.
 - Q2: Будет ли работать на мобильных устройствах?
   A: Да, но только если они подключены к вашему хотспоту и не используют мобильный интернет.
